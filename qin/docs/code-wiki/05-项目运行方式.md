## 5.6 工程红线（改动前必读）

**硬性约束**
1. 所有构建/测试/调试针对真机 UDID `00008110-000411A40EC1401E`，不用模拟器。
2. 新功能必须接 LogManager 全链路埋点（当前基准：37 域 / 1,077 处带域埋点）。
3. 全项目**禁止** `NSAttributedString(data:options:[.documentType:.html])` 解析 HTML —— 只用纯正则。
4. 通知回调同步链禁止弹 sheet（必须走 pendingDeepLink + 等待 active && !isLockEngaged + 让出 runloop）。
5. 图片组件：缩略图 720px / 详情 1440px 下采样；图片响应注入 7 天缓存头（含服务器要求 no-cache 的图片，no-store 除外）。
6. 手动刷新必须清详情缓存 + 推进 cacheGeneration 代际。
7. 基础样式：经典 `.tabItem`（禁 Liquid Glass Tab API）；按钮必加 `contentShape(Rectangle())`；中文文案与注释。
8. 禁止 `@AppStorage + didSet`、`@Sendable Task` 捕获 `inout`；`Timer.publish` 需显式 `import Combine`。
9. App 图标切换仅限用户显式操作 + 系统确认框，禁止后台/自动切换；图标资源名 AppIconAlt1~4 三处保持一致（资源目录/构建设置/代码）。
10. **图片保存到相册（WebP 铁律）**：WebP 等格式 UIImage 经 `creationRequestForAsset(from:)` 写入必触发 PHPhotosErrorDomain 3302——统一 JPEG 重编码 → 临时文件 → `PHAssetCreationRequest.addResource(.photo, fileURL:)` file-based 写入。
11. **消息中心存储强原子写**：文件 JSON 持久化必须「临时文件 + `replaceItemAt` 原子替换 + 写后读回自校验」；损坏备份用时间戳命名保留最近 5 份。清空操作必须红色确认弹窗（提示「未读计数与角标将同步清零」）；关闭角标联动必须 `setBadgeCount(0)` 清零。
12. **SF Symbols 校验**：iOS 26/27 运行时已移除 `magnifyingglass.fill` 等旧符号（真机渲染为空）——新增符号前必须校验存在性（如 `sparkle.magnifyingglass`）。
13. **静态矢量装饰层禁止 `drawingGroup()`**（曾致真机疑似启动黑屏挂起）；Info.plist 必须含 `CADisableMinimumFrameDurationOnPhone = true` 解锁 120Hz。
14. **模块退役必须处理旧值**：HomeModuleManager `retiredRawValues` + init 区分日志级别静默清理（info 级）；helpGuide 相关文章模块总数文案与枚举成员数强耦合。
15. **搜索防抖空态防御**：防抖窗口内旧结果为空时不得显示「未找到」——需 `isSearchPending` +「正在搜索…」指示（helpGuide/消息中心/校园日历同款）。
16. **高密度导航控件必须「预览与提交分离」**（校园设施目录轮播教训）：拖动只移动预览指针，点按才提交跳转；正文滚动指针自动回收。
17. **灰度传播双通道**（2026-09-26 新增红线）：根视图 `.saturation` 不作用于 sheet/fullScreenCover——任何新增内容级 presentation 必须挂 `sjzGrayScale()`（当前 44 处；系统分享面板除外）。
18. **字体体系红线**：中文字体只能用 `DisplayFontFamily` 7 家族（西文字体必致全中文回退苹方、切换无感）；未就绪家族必须走 `ensureFontFamily` 系统下载；下载完成必须经 `typographyRevision` 驱动重建才算生效；字体名/迁移映射改动需同步更新 DisplaySettingsLogicTests。
19. **netmon 采集红线**：台账写入必须线程安全（Ledger/NSLock，非 MainActor）；诊断/测速期间必须 `setSuspended(true)` 静默业务账目；心跳必须受 scenePhase 门控；WKWebView/AVPlayer 流量为系统组件盲区——UI 必须如实标注，不伪造。
20. **微信集成红线**（2026-09-27 新增）：① `registerApp` 只能在用户同意隐私协议后调用；② 配置一律从 Info.plist 读（构建设置 `WECHAT_*` 单点注入），禁止在代码中硬编码 AppID/UL；③ 所有微信操作必须先过 `WeChatAvailability.canOperate`（占位配置下不得发起任何请求）；④ 用户取消 = INFO 日志、不计失败；⑤ SDK 日志必须经 `wechat` 域桥接，禁止直接 print；⑥ `WXApiDelegate` 回调属跨线程，必须 nonisolated 提取原语后回主线程处理；⑦ 新增文章分享入口必须同时挂 `WeChatShareMenu` + `.sjzPresentationChrome()`（否则构建期护栏拦截）。

## 5.8 常见任务速查

- **加一个旧数据域内容模块**：Models.swift 建模型 → NetworkService 加 DTO+fetch → DataService 加加载/缓存键 → TabBar 或独立 View 文件（新文件需四段注册 pbxproj：PBXBuildFile + PBXFileReference + group children + Sources phase，PBX ID 需 grep 防撞）→ 全链路 LogManager 埋点 → 真机构建 + 测试。
- **加一个新业务模块（推荐模式）**：新建 `XxxStore.swift`（@MainActor 单例直连 NetworkService，不经过 DataService 门面）+ `XxxView.swift` + 测试用例追加进既有测试文件（避免 pbxproj 注册）；数据形态特殊时按「校园日历」范式：本地缓存优先 + 三态刷新状态机 + refreshDetached 防取消误报 + 搜索防抖 isSearchPending +（若有 presentation）`sjzGrayScale()` 挂载。
- **改显示设置/字体**：改 Manager 的 @Published 必须同步 persist + log + recordChange 三件套；新增字体家族需过 `DisplaySettingsLogicTests`（迁移映射/字体名/字貌断言）；灰度新增挂载点用 `grep -c "sjzGrayScale()"` 核对总数（当前 45 处含定义）。
- **改网络监测**：任何触碰 URLProtocol/Ledger 的改动先用「网络监测面板 + netmon 域日志（29+ 类事件）」双取证；诊断/测速行为改动需回归「互斥 setSuspended」与「后台心跳暂停」两条时序。
- **排查「成功但 0 条」**：先用真实抓包 JSON 跑独立解码脚本核对 DTO 层级（校长信箱历史教训）；同步路径落 warning 日志携带 page/长度线索。
- **改部署目标**：统一 project 与 target 两处 `IPHONEOS_DEPLOYMENT_TARGET`。
- **图标更换**：更新 5 套 appiconset 资源并核对 AppIconManager 引用与 pbxproj `ALTERNATE_APPICON_NAMES`。
