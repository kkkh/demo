- **网络**：URLSession async/await + RefererHeaderURLProtocol 防护代理，无第三方网络库

### 4.2 数据流

```
远程 API → NetworkService（DTO）→ DataService / 各业务 Store
        → @Published 属性（Manager 单例）→ SwiftUI View
```

## 5. 核心业务模块

### 5.1 首页信息聚合（HomeModuleManager + HomeView）

**12 个可配置模块**（2026-09-24 终版；退役管理见 HomeModuleManager.retiredRawValues）：学校要闻、校园荣誉、通知公告、使用帮助（原「招生信息」升级，含未读光点+进度环+继续阅读）、教师风采、映像校园、学生故事、校园活动、发展历程、校长信箱（信封渐变卡）、党建专题、学校概况。支持开关/排序、0.07s 递增错峰弹簧入场、Apple News 风格骨架屏、SJZIdleTimerRepair 熄屏修复。

### 5.2 校园生活七大分区（CampusView，2026-09-25/26 艺术级升级）

校园服务七色宝石网格（7 项）、机构设置入口卡（渐变横幅+微光扫过）、学校概况卡（地址复制/招生电话拨打/校庆日）、校园设施列表+详情（**6 大新功能**：Liquid Glass 目录轮播/阅读进度条/回顶按钮/一键复制全文/重播动画/定位胶囊）、友情链接（域名副题）、关注我们（二维码保存相册）。全部分区受显示设置管辖、6 个新日志域埋点。

### 5.3 通知与消息中心（NotificationManager + BookmarkManager + MessageCenterStore）

- **四通道指纹轮询**（默认 30 分钟，可配）：新闻（notifiedArticleIds 上限 2000）/ 校长信箱（最新一条）/ 学校概况（基线 7|10|29）/ 党建专题（djgz|mkszy 四段指纹）——无服务端条件下自建的本地推送体系
- **收藏第五通道**：BookmarkManager 每小时比对收藏正文 SHA256 指纹 →「收藏文章已更新」通知（≤3 条）
- **消息中心**：五通道站内信（MessageKind：新闻/信箱/概况/党建/收藏更新），日分组 UI、左滑删除/右滑已读/长按菜单、全部已读三态、设置面板、长按铃铛 5 次诊断修复；落盘强原子写 + 损坏文件抢救；每次推送先入盒再弹横幅

### 5.4 学校概况 / 党建专题 / 校长信箱 / 使用帮助 / 校园日历（自包含 Store 模式）

| 模块 | 要点 |

### 5.5 生物识别安全锁 / 收藏 / 隐私 / 公告

- **生物识别**：三态状态机（locked/authenticating/unlocked）；冷启动+后台返回+敏感页锁定；连续 5 次失败降级设备密码；Keychain 门控；遮罩防多任务预览泄露
- **收藏**：上限受缓存模式控制（LRU 淘汰）；正文+图片（SHA256 键、NSCache 96/40MB 双限制、BookmarkImages/*.img）缓存；每小时更新轮询（第五通道）
- **隐私**：首次启动同意弹窗；拒绝 → 受限模式（stopPolling 停止采集）；协议三级降级（网络→缓存→离线文本）；⚠️ PrivacyPolicyView 含 `exit(0)`（审核红线）
- **公告**：独立 URLSession 拉 43322.cn；标题关键字判定；首页胶囊露出

### 5.6 缓存模式 / 显示设置 / 日志 / 网络监测

- **缓存模式**：**两档**（即时刷新 ↔ 缓存模式）；容量决策向下渗透（图片/收藏/详情缓存）；命中率统计；内存警告降载；10 分钟同步短路

## 7. 网络层

### 7.1 请求架构

```
NetworkService（@unchecked Sendable 单例）
  ├── get<T>(path:params:as:) —— 统一 GET：15s 超时、2 次重试指数退避、
  │    URLError.cancelled 立即传播不重试
  ├── cachedSession —— 详情缓存（reloadIgnoringLocalAndRemoteCacheData）
  ├── 20 个领域方法（fetchHome2…fetchMessageDetail，行号见 docs/code-wiki/03 §3.3）
  └── 图片响应注入 7 天 Cache-Control（no-store 除外）
```

### 7.2 防盗链机制（RefererHeaderURLProtocol，232 行）

拦截 `*.sxjzit.edu.cn` → 注入浏览器级 Referer + iOS Safari UA → 递归保护标记 → 解决 AVPlayer/图片防盗链 403；同时为网络监测记账埋点。⚠️ 全局拦截，改动需先确认。

### 7.3 特殊处理

- DTO 全 Optional + CodingKeys 显式映射；`AnyCodable` 处理不规则 JSON
- 纯正则 HTML 解析（**禁止** NSAttributedString(documentType:.html)）
- 图片 URL 安全编码（相对转绝对/非 ASCII 编码/过滤 file://）
- 无 Token、无签名、无登录态（公开读接口）

## 10. 代码规范与模式

### 10.1 架构模式：MVVM + Singleton Manager

```swift
@MainActor
final class XxxManager: ObservableObject {
    static let shared = XxxManager()
    @Published var someState: SomeType          // 视图 @ObservedObject 直连
    private init() { /* 恢复持久化状态 */ }
}
```

18+ 个 Manager/Store 单例全部遵循此模式；`NetworkService` 为唯一 `@unchecked Sendable`。

### 10.2 并发模型

- 所有 Manager 标记 `@MainActor`；`@Published` 变更在主线程
- 网络用 async/await；详情预取用 `Task.detached`
- 禁止 `@Sendable Task` 捕获 `inout`；`Timer.publish` 需显式 `import Combine`

### 10.3 持久化约定

布尔值区分「从未设置」；枚举字符串映射；Codable JSON 编解码；Key 定义为 `private static let xxxKey`。

### 10.4 静态默认数据模式

`Models.swift` 为每个模型提供 `default*` 静态数组（12 荣誉/11 院系/44 专业/5 设施/7 服务/…），离线兜底。

### 10.5 日志系统规范

`info / debugLog / warning / error / fatal` 五级 + domain（**36 个日志域**）+ context 字典；结构化 JSON（毫秒时间戳）；异步写入不阻塞 UI；崩溃捕获同步写。

### 10.6 命名约定

文件/类型 PascalCase；方法 camelCase；中文注释；中文用户文案；文件后缀 `*Service/*Manager/*Store/*View`。

### 10.7 自包含业务模块范式（2026-09-24 起）

新模块 = 私有 `XxxStore`（@MainActor 单例直连 NetworkService，不经过 DataService 门面）+ 独立 View + 测试追加进既有测试文件（避免 pbxproj 注册）。数据形态特殊的按「校园日历范式」：本地缓存优先 + 三态刷新状态机 + `refreshDetached` 防取消误报 + 搜索防抖 `isSearchPending`。
