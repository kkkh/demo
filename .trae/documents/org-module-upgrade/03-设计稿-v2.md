## 0. 总纲（五原则 + 一条铁律）

**概念：「书院典藏 × 液态玻璃」** —— 内容（文字/数字）是主角，材质退后服务内容。

| # | 原则 | 表述 | 铁律 |
|---|---|---|---|
| 1 | 内容优先 | 版式/间距/色彩都为"读得舒服"服务 | 装饰性渐变 0；贴纸色块 0 |
| 2 | 克制的贵气 | 铜金点睛 ≤5% 面积；主色只用于可交互与强调 | 高饱和撞色 0；金光 0 |
| 3 | 材质真实 | 玻璃只用于浮动层（吸顶 chips/工具条/当行导航）；内容层哑光实体面 | 内容卡堆玻璃 0 |
| 4 | 一处处治 | 每个细节一个规范来源（§1.4 令牌表 + §4 动效表） | 局部特批 0 |
| 5 | 活体数据 | 每个栏目标题带 total 真值；下拉/前台/推送三通道同步 | 可见即最新 |
| ＋ | **九形态铁律** | 官网 18 类 componentType **逐类映射**到九形态之一（§2.2），任何栏目都有内容壳 | 「需在官网查看」0 |

### 3.5 UI 显微打磨（v2.2 新增 · 每个像素都被设计过）

**① 列表卡视觉节奏（避免满屏纯文字堆砌）**
- 节奏模型：**大图卡（16:9 缩略图 + 标题 2 行 + 摘要）→ 文字卡（铜金「月·日」日期徽章 + 标题 + 摘要）→ 标题分隔行** 交替；同屏 ≤1/3 大图卡。
- 日期徽章：`MM.DD` 竖排铜金 10.5pt + 细线，序列连续感（图书馆排架隐喻）。
- 缩略图占位 = 平均色 + 线性示意（`photo` 符号 20% 透明），拒绝灰块。

**② 题头与行细节**
- 机构题头：图标徽章 48 + 名称（H1）+ 分类胶囊 + 「N 栏目 · 共 M 篇」副行；**档案纸感** = 1px `line` 上细线 + 铜金 2pt 饰线（≤5%）。
- 行内缩进：列表 16；区块 20；list row 高 ≥52（触控）。
- 分割：行间 1px `line` 85% 全宽；组间留白（空格）优先于分割线（克制）。

**③ 状态与反馈的"微表情"**
- 按压：整卡 `scale 0.97` + 材质亮度 +0.03（无阴影位移）；触觉自然由系统。
- 选中条（chips）：墨蓝填充 + 阴影提升 `0 6 14 tint 30%`；**切换携带动画把旧 chip 淡出、新 chip 淡入 + 列表 y 向 6pt 上移涌入**。
- 计数数字全部 `monospacedDigit()` + tabular 对齐（「已显示 240 / 653」不跳位）。
