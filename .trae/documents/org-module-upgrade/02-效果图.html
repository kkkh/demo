一 · 配色方案（三备选 → 选定 A）

三套方案均为浅/深完整实现。裁决维度：与全 App 色板血缘、内容语义、（浅/深）双模式耐看度、与内容页抢色风险、无障碍实算。结论：选定 A「青金书院」——暖纸白 + 墨蓝 + 铜金点睛，档案气质、低饱和、有出处；B 与全局蓝系不同源（切换 Tab 像另一个 App），C 与既有 sjzAccent 无区分度且副色对比度不足 AA。

A 青金书院 选定

暖纸白 bg#F7F5F0 / #0F141B
墨蓝 主色#1E3A66 / #9FB9E6
铜金 点睛#8F7038 / #D8BC8A
分类五色（降饱和）恒定语义色
档案纸 × 钢印 × 铭牌。铜金占比 ≤5%（精选徽标 / 内容规模数字 / 饰线）。全部关键对比度 ≥4.5:1（实算）。

B 石青

冷灰米白 bg#F5F7F6 / #0E1413
石青绿 主色#2F6D63 / #7FC7B8
雾青 副色#6E8FA3（3.43:1 仅大字）
知性常青藤气质；但与全局海军蓝主题不同源，跨 Tab 观感割裂，且青绿与党建绿存在混淆风险。

C 苍穹

冷白 bg#F6F8FB / #0B1220

浅青 副色#79A7D8（2.52:1 仅装饰）
科技感强、与玻璃材质合拍；但与既有 sjzAccent #1A56B8 几乎同色，模块无辨识度，副色不达 AA。

节奏手法（华容道式）

七 · 振动分级规范（OrgHaptics 六级）

每一处强提示、重要操作都有独立强度：同一操作在"触发-完成-失败"的不同阶段也分级（如下拉刷新：触发=柔 → 完成=success）。

级别生成器强度语义与全操作映射
选择 selectionUISelectionFeedback平级切换：分类 chips · 栏目 chips · 排序切换
轻 lightimpact(.light)完成/进入：进入详情 · 加载更多到达 · 打开图片
柔 softimpact(.soft)开始/触发：下拉刷新触发 · 玻璃吸顶首次出现 · toast 出现
中 mediumimpact(.medium)状态改变：收藏 · 关注 · 长按菜单弹出 · 字号 A-/A+
锐 rigidimpact(.rigid)边界/干脆：翻到底（无更多）· 回弹到顶/底 · 空态刷新无变化
系统通知 notification.success/.warning/.error结果：关注成功=success · 弱网降级=warning · 加载失败=error
